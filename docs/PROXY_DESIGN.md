# 主机代理设计

## 当前实现
- 已支持主机组、主机和代理节点的 SQLite 登记与 API 管理。
- 已支持主机与主机组、代理的关联，以及 Web 资产管理。
- **代理只是库存元数据**，状态为 unconfigured；不提供远程任务分发或隧道。
- 现有诊断 API 仍按 DIAG_ALLOWED_HOSTS 直接 SSH，绝不因登记代理而隐式转发。

## 后续生产代理协议
1. 代理主动向中央服务发起 mTLS 连接，不开放入站管理端口。
2. 每个代理有独立身份、独立 SSH 凭据和固定可达 CIDR；证书轮换及撤销。
3. 中央下发结构化动作与目标主机 ID，不下发任意 Shell。
4. 代理校验目标清单、动作白名单、参数、签名、TTL 和一次性任务 ID。
5. 强制命令网关再次校验，只返回大小和时长受限的结果。
6. 任务队列、心跳、离线重试、审计日志及日志脱敏。
7. 多代理之间默认不互通，不允许横向代理转发。
